# Bookify

App Android para gestionar y descubrir libros.

## Stack

- **Lenguaje:** Kotlin
- **UI:** Jetpack Compose + Material3
- **Arquitectura:** MVVM + Clean Architecture
- **DI:** Hilt
- **Networking:** Retrofit + OkHttp + KotlinX Serialization
- **Local:** DataStore Preferences + Security Crypto
- **Firebase:** Analytics + Crashlytics
- **Navigation:** Compose Navigation
- **Otros:** Paging Compose, Google Play Services Location

## Módulos

- `app` — Capa de presentación
- `core:domain` — Casos de uso y modelos
- `core:data` — Repositorios y fuentes de datos
- `core:network` — API y servicios remotos

## Configuración

1. Clona el repositorio
2. Abre en Android Studio
3. Sincroniza Gradle
